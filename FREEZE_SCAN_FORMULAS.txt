Squall Freeze + Scan Formula Notes
==================================

File of implementation:
- src/clouds_reverb.cc

Control normalization
---------------------
scan_raw in [0, 1] from parameter slot 4 (SCAN)
scan_smoothed = one_pole(scan_smoothed, scan_raw, k_scan_smoothing)

freeze_target = 1 when FREEZE on, else 0
freeze_blend = one_pole(freeze_blend, freeze_target, k_freeze_smoothing)

Base reverb controls
--------------------
base_amount = reverb_amount * k_amount_scale
base_time   = k_time_base + k_time_scale * reverb_amount
base_lp     = k_lp_base + k_lp_scale * tone

Inverse SCAN -> leak mapping (requested behavior)
-------------------------------------------------
k_freeze_leak_max = 0.05   (5%)
freeze_leak = (1 - scan_smoothed) * k_freeze_leak_max

This yields:
- SCAN = 1.0 (100%): freeze_leak = 0.0   -> tightest hold
- SCAN = 0.0 (0%):   freeze_leak = 0.05  -> slight decay/new input

Freeze hold and input path
--------------------------
freeze_hold = freeze_blend * (1 - freeze_leak)
input_scale = (1 - freeze_blend) + (freeze_blend * freeze_leak)

Reverb core parameters
----------------------
amount      = base_amount + (1 - base_amount) * freeze_hold
reverb_time = base_time   + (1 - base_time)   * freeze_hold
input_gain  = k_input_gain_base * input_scale

SCAN color/motion (does not modulate reverb_time)
--------------------------------------------------
scan_bipolar = (scan_smoothed * 2 - 1)
scan_shaped  = scan_bipolar^3
scan_amount  = scan_shaped * freeze_blend

lp        = clamp01(base_lp + (1 - base_lp) * freeze_hold + 0.18 * scan_amount)
diffusion = clamp01(0.7 + 0.10 * scan_amount)

Plain English Summary
---------------------
- FREEZE is the main hold switch.
- SCAN does two things while frozen:
  1) sets how strict the hold is (from perfect hold to a tiny 5% leak),
  2) changes the frozen tone/texture through LP + diffusion.
- SCAN does not directly change reverb_time in this revision.

Quick tuning guide
------------------
- To allow more bleed while frozen, increase `k_freeze_leak_max`.
- To make SCAN feel more dramatic, increase LP/diffusion multipliers.
- To make SCAN feel less jumpy, reduce `k_scan_smoothing`.
